# Шаблон финального конспекта

Готовый файл собирает `assemble_md.py` из рабочих файлов в `work/<Автор>. <Название> [<video_id>]/`.
Структура жёсткая, содержимое секций пишут субагенты конвейера.

Правила форматирования, общие для всех секций:

- Язык — русский.
- Подзаголовки: `### <эмодзи> <Заголовок>`; эмодзи только в подзаголовках, по одному.
- Текст идёт сразу после строки подзаголовка, без пустой строки между ними.
- Линии `---` — только между тремя большими секциями, не внутри них.
- Важные цифры, имена и термины — жирным. Хайлайты `==...==` не использовать: они зарезервированы для ручного выделения человеком при чтении.
- Одна пустая строка между абзацами, никаких двойных пустых строк.

---

Итоговая структура файла:

    ```vid
    <ссылка на видео>
    Title: <название видео>
    Author: <автор/канал>
    Thumbnail: <ссылка на превью>
    AuthorUrl: <ссылка на канал>
    ```

    ## Саммари
    <объединённое подробное саммари: ### подзаголовки с эмодзи, раскрытая суть
    каждого пункта, важные детали из всех раундов дополнений — ничего не
    потеряно, повторов тезисов нет>

    ---

    ## Мои заметки
    <раздел остаётся пустым — заготовка для пользователя. Сюда пользователь
    дописывает свои заметки, а при вопросах по видео агент добавляет короткие
    пары «вопрос — ответ» в формате:

    **<краткий вопрос>**
    <сжатый ответ: 2–4 предложения, только суть.>>

    ---

    ## Стенограмма
    ### <эмодзи> <Название главы 1>
    **<Имя>:** <реплика>

    **<Имя>:** <реплика>

    ### <эмодзи> <Название главы 2>
    ...
    <полная стенограмма на русском: для диалогов — реплики с подписями говорящих
    (имена из контекста, иначе «Спикер 1/2»), для монологов — связный текст по главам>
