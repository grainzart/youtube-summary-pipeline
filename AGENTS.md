# youtube-summary-pipeline

Автоматизация конспектов YouTube-видео: субтитры → многоэтапная саммаризация на русском → готовый .md по шаблону Obsidian.

## Правила проекта

- Когда пользователь присылает ссылку на YouTube и просит конспект/саммари (или просто кидает ссылку) — используй скилл `youtube-summary` (`.agents/skills/youtube-summary/SKILL.md`), включая режим вопросов после конспекта (шаг 5 скилла).
- Все файлы создаются только внутри папки этого проекта, ничего не писать вне её.
- Python-скрипты запускать только через `uv run` (окружение `.venv` уже настроено, зависимость — `yt-dlp`).
- Рабочие промежуточные файлы — в `work/<Автор>_<Название>_[<video_id>]/` (без пробелов, gitignore, не удаляются — по ним можно отвечать на вопросы после конспекта), готовые конспекты — в `summaries/` (с пробелами, для Obsidian).
- Стиль конспектов: русский язык, подзаголовки `### <эмодзи> <текст>`, эмодзи только в подзаголовках, без пустой строки после подзаголовка, без `---` внутри секций, важное — жирным; хайлайты `==...==` не генерировать (зарезервированы для ручного выделения пользователем). Полные правила — в `TEMPLATE.md`.
- Раздел «## Мои заметки» в конспекте остаётся пустым (заготовка пользователя); заметки в него добавляет только агент по сценарию шага 5 скилла, коротко (2–4 предложения на вопрос).
