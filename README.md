# youtube-summary-pipeline

Инструмент для саммаризации YouTube-видео: по одной ссылке скачивает субтитры,
многоэтапно саммаризирует на русском и собирает готовый .md-конспект
(подробное саммари + пустой раздел «Мои заметки» + полная стенограмма по главам).

## Установка

Нужны git и uv (менеджер проектов Python, https://docs.astral.sh/uv/);
Python 3.12+ uv при необходимости скачает сам.

```bash
git clone https://github.com/grainzart/youtube-summary-pipeline.git
cd youtube-summary-pipeline
uv sync
```

## Использование

### В ZCode

Открой папку проекта и кинь в чат ссылку на YouTube-видео (можно просто ссылку,
можно со словами «сделай конспект») — сработает скилл `youtube-summary`:
скачает субтитры, прогонит конвейер саммаризации и положит готовый файл
в `summaries/`. После конспекта можно задавать вопросы по видео прямо в чате:
агент ответит по стенограмме и по желанию кратко добавит ответ в «Мои заметки».

### Универсально (любой агент или вручную)

Конвейер описан в `.agents/skills/youtube-summary/SKILL.md`: его выполнит любой
LLM-агент, умеющий следовать инструкциям и запускать команды. Скрипты
самодостаточны и работают из любого терминала:

```bash
uv run fetch_subs.py "<URL>"                  # субтитры + метаданные
uv run fetch_subs.py "<URL>" --lang en        # принудительный язык
uv run fetch_subs.py "<URL>" --timestamps     # абзацы с метками [ММ:СС]
uv run assemble_md.py --work "work/<папка>"   # сборка готового md
uv run assemble_md.py --work "work/<папка>" --out "X:/путь/файл.md"
```

Оба скрипта печатают на stdout одну строку JSON с результатом.

## Как работает конвейер

1. `fetch_subs.py` скачивает субтитры (yt-dlp) и метаданные в
   `work/<Автор>_<Название>_[<video_id>]/` (без пробелов — удобно в терминале).
   Субтитры качаются на языке оригинала видео: язык определяется по метаданным
   и оригинальной автораскадровке (у видео с дубляжами берётся именно оригинал,
   а не перевод); если оригинал не ru/en — автоперевод (ru, затем en).
2. Субагенты прогоняют этапы: подробное саммари → раунды дополнений упущенного
   (до 3, пока раунд не ответит «важного не осталось»), параллельно — полная
   стенограмма с главами; в конце — умное объединение без потерь.
3. `assemble_md.py` собирает готовый файл по `TEMPLATE.md`
   в `summaries/<Автор>. <Название видео>.md` (с пробелами — для Obsidian).

Именование: папки `work/` — подчёркивания вместо пробелов (терминал-friendly),
файлы `summaries/` — с пробелами (в стиле заметок Obsidian). Запрещённые
символы (`/ | : * ? " < > \`) в названиях заменяются.

## Структура

- `fetch_subs.py` — субтитры, очистка автораскадровки от скользящих повторов, метаданные.
- `assemble_md.py` — детерминированная сборка готового md (нормализация отступов, срез хайлайтов).
- `TEMPLATE.md` — шаблон и правила форматирования конспекта.
- `.agents/skills/youtube-summary/SKILL.md` — скилл ZCode: оркестрирует весь конвейер и режим вопросов.
- `work/` — промежуточные файлы (gitignore, сохраняются между прогонами), `summaries/` — готовые конспекты.
